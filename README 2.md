# Icod-Añaza Centre · Kasino

Juego de apuestas con dinero ficticio. Es un sitio estático: un único `index.html`, sin dependencias.

## Publicar en Render
1. Sube esta carpeta a un repositorio de GitHub.
2. En Render: New > Static Site, y elige el repositorio.
3. Build Command: vacío (o `echo sin build`). Publish Directory: `.`
4. Create Static Site.

También puedes usar New > Blueprint, que lee `render.yaml`.
